# Карта английских времён

Интерактивная методичка по всем двенадцати временам английского языка для занятий с учениками.

**Открыть:** https://alex-thepilot.github.io/english-tenses-map/

## Что внутри

Всё построено на одной идее: времён не двенадцать, а **3 × 4**. Время собирается из двух деталей — «когда» задаёт вспомогательный глагол, «как» задаёт форму смыслового.

- **Матрица-конструктор 3 × 4** — клик по клетке собирает формулу из деталей и показывает пример.
- **Маршрут из четырёх уровней** — Simple → Continuous → Perfect → Perfect Continuous, двенадцать станций. У каждого времени свой анимированный таймлайн: цвет кодирует время (прошлое / настоящее / будущее), форма кодирует аспект (точка, волна, дуга, волна со счётчиком).
- **Пять дуэлей** — пары, в которых путаются все: Past Simple vs Present Perfect, Perfect vs Perfect Continuous, will vs be going to и другие.
- **Схема-развилка** для главной ошибки: Past Simple / Present Perfect / Present Perfect Continuous.
- **Тренажёр** на двенадцать вопросов с объяснением после каждого ответа.
- **Шпаргалка** одной таблицей — годится для печати.

Тёмная и светлая темы, переключатель в шапке. Отметки «изучено» хранятся в браузере ученика (`localStorage`) и никуда не отправляются.

## Как отдать ученику

Просто ссылка выше — страница работает на телефоне и на компьютере, ничего устанавливать не нужно.

Если нужна офлайн-версия, скачайте `index.html` и отдайте файлом: он открывается двойным кликом. Без интернета не подгрузятся шрифты (Unbounded, Golos Text, JetBrains Mono) — вёрстка останется целой, сменится только начертание.

## Как править

Весь материал — один файл `index.html`, без сборки и зависимостей. Тексты времён лежат в массиве `T` внутри `<script>`: у каждого времени есть `thesis` (мысль одной строкой), `lead`, `blocks` (объяснения, ловушки), `forms`, `markers` и `ex` (примеры). Вопросы тренажёра — в массиве `Q`, дуэли — в `DUELS`.

После правки закоммитьте и запушьте в `main` — GitHub Pages обновит сайт за минуту-другую.
