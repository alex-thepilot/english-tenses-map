# Карта английской грамматики

Интерактивная методичка для занятий с учениками. Одна страница, две вкладки: **времена** и **условные предложения**. Устроена так, чтобы легко добавлять новые правила отдельными вкладками.

**Открыть:** https://alex-thepilot.github.io/english-tenses-map/

## Что внутри

### Вкладка «Времена»
Всё построено на одной идее: времён не двенадцать, а **3 × 4**. Время собирается из двух деталей — «когда» задаёт вспомогательный глагол, «как» задаёт форму смыслового.

- Матрица-конструктор 3 × 4: клик по клетке собирает формулу из деталей.
- Маршрут из четырёх уровней, двенадцать станций. У каждого времени анимированный таймлайн: цвет кодирует время (прошлое / настоящее / будущее), форма — аспект (точка, волна, дуга, волна со счётчиком).
- **После каждого времени — 10 заданий** с разбором каждого ответа.
- Пять дуэлей: Past Simple vs Present Perfect, Perfect vs Perfect Continuous и другие.
- Общая проверка: 24 вопроса, по два на каждое время.

### Вкладка «Условные предложения»
Главный тезис: **часть с `if` всегда стоит на одно время раньше результата**. Говорим про будущее — в условии настоящее, про настоящее — прошедшее, про прошедшее — предпрошедшее.

- Определитель типа: два вопроса («сколько “бы” в переводе» → «про какое время речь») и тип назван.
- Лестница шага назад одной схемой.
- Семь станций: Zero, First, Second, Third, Mixed, инверсия без `if`, конструкция `I wish`.
- **После каждого типа — 10 заданий**, плюс общая проверка на 14 вопросов.

Всего **228 заданий**. В каждом после ответа появляется разбор: почему верный вариант верный и чем именно плох выбранный — независимо от того, угадал ученик или нет.

Тёмная и светлая темы. Отметки «изучено» хранятся в браузере ученика (`localStorage`) и никуда не отправляются.

## Как отдать ученику

Ссылка выше — страница работает на телефоне и на компьютере, ставить ничего не нужно.

Нужна офлайн-версия — скачайте `index.html` и отдайте файлом, он открывается двойным кликом. Без интернета не подгрузятся шрифты (Unbounded, Golos Text, JetBrains Mono); вёрстка останется целой, сменится только начертание.

## Как править

Страница собирается из модулей в папке `src/`. После любой правки:

```bash
bash src/build.sh
```

Скрипт пересобирает `index.html` в корне — именно его отдаёт GitHub Pages. Дальше обычный `git commit` и `git push` в `main`, сайт обновится за минуту-другую.

### Формат задания

```js
Q('If it ___ tomorrow, we will stay in.',
  ['+rains',    'После if будущее выражают настоящим временем.'],
  ['will rain', 'После if will не ставят — это одно из самых устойчивых правил.'],
  ['rained',    'Прошедшее сделало бы дождь воображаемым.'])
```

Плюс в начале помечает верный вариант. Пояснение пишется **у каждого**: у верного — почему он верный, у остальных — чем они плохи. Ученик видит разбор своего выбора и правильного ответа рядом.

### Как добавить новое правило вкладкой

1. Скопируйте `src/30-data-cond.js` как образец — там станции, уровни и дуэли одного правила.
2. Задания положите рядом по образцу `src/35-drills-cond.js`.
3. В `src/02-body.html` добавьте кнопку в `.tabs` и блок `<div class="tabpanel" id="tab-…" hidden>`.
4. В `src/40-app.js` допишите запись в `TABDEF` (разделы для оглавления и меню) и вызовите `renderRoadmap`.
5. Перечислите новые файлы в списке в `src/build.sh` и пересоберите.
